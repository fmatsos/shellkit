# Shell config: where things go and how to change them

Plain zsh (default shell) and plain bash (fallback), with no framework. Don't
bring back Oh My Zsh or Oh My Bash: dropping OMB took startup from 254 ms to about 30 ms and
removed its side effects (noclobber surprises, `CDPATH=.` echoing paths, aliases).

## Where a setting belongs

| What | Where |
|------|-------|
| token, API key, password | `~/.config/shkit/secrets.sh` (chmod 600), sourced **last**; repo uses `$VAR` only |
| machine-specific (hosts, extra `PATH`s, env flags like `ENABLE_LSP_TOOL`) | `~/.config/shkit/settings.sh` |
| prompt look (segments, colors, icons) | `~/.config/shkit/theme.zsh`, zsh only (see `prompt-theme`) |
| prompt settings for one project | `~/.config/shkit/projects/<name>.zsh`, via `shkit` (see `prompt-theme`) |
| prompt block for this machine only | `~/.config/shkit/prompt.d/<name>.zsh` (see `prompt-theme`) |
| prompt blocks / themes from a git repository | `~/.config/shkit/plugins/<name>/`, via `shkit plugin add URL` (see `prompt-theme`) |
| alias or function for both shells | `shell/aliases.sh`: portable, no bash-only or zsh-only syntax |
| alias or function for this machine only (work tools, client paths) | `~/.config/shkit/aliases.sh`, sourced right after it |
| zsh-only (options, zle widgets, completion styles) | `zsh/zshrc` |
| bash-only | `bash/bashrc`, `bash/completion.sh` |
| runs even for non-interactive zsh | `zsh/zshenv`: keep it near-empty |

Load order in `zshrc`:
1. options, history, keys, completion;
2. `~/.config/shkit/settings.sh`;
3. `shell/aliases.sh`, then `~/.config/shkit/aliases.sh`, then `prompt.zsh`, which reads `theme.zsh`, `projects/`,
   `plugins/` and `prompt.d/` in layers;
4. `~/.config/shkit/secrets.sh` last.

`bashrc` mirrors this, without the theme.

Every file outside the repo goes in `~/.config/shkit/` (`$SHELL_LOCAL_DIR`, set at the top
of both rc files, so it can't be moved from a file inside it). A new one: add it to
`shell/install-local.sh` if it replaces an old path, never a new dotfile in `$HOME`.

## Changing things

- **Option parity**: autocd, noclobber (write with `>|`), `**` recursion, spelling fixes
  (bash `cdspell`/`dirspell`, zsh `_approximate` completer), unlimited shared history,
  ↑/↓ prefix search, Esc Esc to toggle `sudo`, colored `man`. A change to one of
  these goes in both rc files.
- **zsh only**: a directory's last segment alone = `cd` to the most recent visited
  one (`_zshrc_jump`, bound to `accept-line`; the list is `cdr`'s). Bash stays without it.
- **Completions**: generated by `zsh/install.sh` / `bash/install.sh` through their
  `gen OUTPUT CMD…` helper. zsh-native files go to
  `~/.local/share/zsh/site-functions`; bash-style ones are loaded through `bashcompinit`.
  After adding one, delete `~/.cache/zsh/zcompdump` (the install script does it).
- **`skip_global_compinit=1`** in `zshenv`: Ubuntu's `/etc/zsh/zshrc` otherwise
  runs a second compinit (startup went 31 → 140 ms). `SHELL_SESSIONS_DISABLE=1`
  there too: macOS Terminal.app would keep one history per tab.
- **No locale** (a GUI-launched terminal): `zshrc` sets `LC_CTYPE` to UTF-8 before
  the prompt, whose `$'\u…'` icons fail to parse otherwise.
- **macOS**: Homebrew's `/opt/homebrew` is added to `path`/`fpath` by hand in both rc
  files (no `brew shellenv`: a fork at every start). `bashrc` stops early below bash
  5.1 (macOS's `/bin/bash` is 3.2); install scripts must still run on 3.2 (no
  `declare -A`, no `${x,,}`). Files outside the repo: try each OS's path in turn
  (`git-sh-prompt`, `bash_completion`), and keep a fallback when none is found.
- **History**: `~/.zsh_history` uses the extended format. `zsh/install.sh` imports
  `~/.bash_history` once, only when `~/.zsh_history` doesn't exist.
- **New alias shadowing a command** (`cp -iv`, `mkdir -pv`…): scripts sourced into
  the shell must then call `command mkdir` etc.

## Verifying

- Clean environment, both shells:

  ```bash
  env -i HOME=$HOME TERM=xterm-256color PATH=/usr/bin:/bin zsh -ic '<check>'
  env -i HOME=$HOME TERM=xterm-256color PATH=/usr/bin:/bin bash --rcfile bash/bashrc -ic '<check>'
  ```

- Check exported values without printing secrets: compare names, or use
  `[[ -n $VAR ]]`, never `echo $VAR`.
- `.claude/skills/config-commit/check.sh` covers syntax, the prompt self-check,
  startup (≤ 60 ms) and the secret scan. Then commit with `config-commit`.
- Open shells keep the old config until `exec zsh` or `exec bash`.

## Hands off

- `~/.bash_aliases` and `~/.bashrc.pre-config` (legacy, plaintext secrets): don't
  touch them without the user's explicit go.
- `~/.claude/statusline-command.sh` is not part of this repo's shell work.
